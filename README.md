# 隙光行者 RIFTLIGHT 2.0

A **multi-file** pixel precision platformer. Celeste-inspired movement with a sandbox lab, a room editor, four visual themes, three languages, procedural Web Audio, animated pixel-art sprites, achievements and local saves.

**No build step. No framework. No runtime network requests.** Open `index.html` directly or serve this folder with any static server.

## Play

**GitHub Pages:** https://hayes314.github.io/riftlight/

- Local: `python3 -m http.server 8765` → `http://localhost:8765/`
- Repository: https://github.com/Hayes314/riftlight

## Controls

| Action | Keyboard | Touch |
|---|---|---|
| Move / climb | Arrow keys / WASD | Floating joystick |
| Jump (hold for height) | Space / Z | JUMP |
| Dash (8 directions) | X / Shift | DASH |
| Grab & climb walls | C / Ctrl | GRAB |
| Resonance burst | V | BURST (when ready) |
| Drop through one-way platform | Down + Jump | Joystick down + JUMP |
| Retry room | R | — |
| Pause | Esc / P | Pause button |
| Mute / theme | M / T | Settings |

Mouse supports all menus, sliders and the Rift Forge editor.

## 2.0 changes

- **Multi-file architecture:** `index.html`, `css/style.css`, ordered plain scripts in `js/`, generated PNG sprites in `assets/`.
- **Animated hero sprite sheet:** 16×20 px, 16 color palettes, rows for idle / run / jump / fall / dash / climb / death. Feet-anchored so the 12×16 collision box and visible body stay aligned.
- **New visual language:** chapter-specific hanging vines, chains, cables, runes, weather (snow, embers, sparks, clock dust), grass/ice/ash details, and a larger animated menu hero.
- **Game-feel pass:** dash camera punch, perfect-landing ring + shake, footstep synthesis and dust, sprite afterimages, boss debris warnings, and a playable finale sequence with prologue/epilogue.
- All prior systems remain: 6 chapters × 8 rooms, boss escape, gauntlet, daily seeds, endless mode, contracts, 12 elements, 8 reactions, 6 sigils, 18-node tree, editor, 16 achievements, i18n, themes, save import/export.

## Project layout

```text
index.html          Shell + meta + ordered script tags
css/style.css       UI, themes, responsive layout, editor/touch styles
js/00-core.js       constants, utils, input, data tables
js/00-assets.js     sprite-sheet loader (graceful fallback)
js/01-i18n.js       zh-TW / zh-CN / en dictionaries
js/02-themes.js     4 themes + Canvas palette interpolation
js/03-audio.js      procedural SFX + generative BGM
js/04-save.js       LocalStorage, achievements, import/export
js/05-levels.js     deterministic room generation
js/06-engine.js     player FSM, physics, modes, boss, effects
js/07-render.js     Canvas renderer, particles, chapter decor, sprite animation
js/08-ui.js         DOM UI, HUD, modals, touch deck
js/09-editor.js     Rift Forge editor
js/10-boot.js       boot, fixed-step loop, focus protection
assets/player.png   16-palette × 6-row hero sheet, generated in-repo
tools/              asset generator and Playwright/jsdom test harnesses
```

## Notes

- The sprite sheet is generated by `tools/make-player-sheet.py` (pure Python/zlib, no image libraries). The runtime falls back to a procedural silhouette if the PNG cannot load.
- All audio is synthesized at runtime through the Web Audio API; no audio files are shipped.
- Deployed to GitHub Pages from `Hayes314/riftlight`.
